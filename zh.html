关于我

我目前是中国科学院大学博士研究生，导师为何苯教授，在中国科学院软件研究所中文信息处理实验室开展研究，预计于2028年毕业。

我于2023年本科毕业于吉林大学唐敖庆理科试验班（计算机方向），获理学学士学位。自2023年9月起在小红书实习，并于2025年7月转为 Ace 顶尖实习生。

研究方向

我的研究聚焦大语言模型后训练，重点包括奖励建模、Agent 与递归自我改进（RSI）。我关注如何通过可靠的奖励信号与强化学习，提升 Agent 的推理和工具使用能力；在 RSI 方向，探索由 Agent 自动完成数据生成、评估与训练，支持模型能力的持续迭代。随着模型能力增强，我也关注如何通过可扩展监督，使这一过程保持可靠与对齐。

研究与实践

小红书2023年9月 — 至今

2025年7月起为 Ace 顶尖实习生。围绕大模型后训练，开展奖励建模、Agent 与递归自我改进系统相关工作。

  • 奖励模型迭代。结合偏好反馈、幻觉检测与过程奖励迭代 RLHF 奖励模型，评估下游效果，并探索可扩展监督机制。
  • Math Verification Agent。先基于 Lean、Python 与自然语言验证器构建 Agent，再通过 SFT 与 Agentic RL 增强验证能力，提升 ProofBench 表现。
  • SWE Coding Agent。搭建 Docker/Kubernetes 采样链路，实现大规模轨迹获取与验证，通过 SFT 检验数据效果；实现 TITO、R3 与 partial rollout，支持 Agentic RL，提升 SWE-bench Verified、Multilingual 与 Pro 表现。
  • Automated Posttrain。在云端 GPU 集群上构建大规模数据合成链路，利用 world model 定向合成，并在训练与推理侧实现分段 tokenization，提升 PostTrainBench 表现。
中国科学院软件研究所 · 中文信息处理实验室2023年3月 — 2023年8月

参与基于 Megatron–DeepSpeed 的大模型预训练工作，包括 LLaMA 训练支持、Checkpoint 转换与数值精度对齐，以及 Kernel Fusion、Flash Attention 等训练优化。

工具与资源

一些我开发的、你可能觉得有用的小工具，欢迎让你的 Agent 试一试。

Skynet ↗

面向 Codex 与 Claude Code 的原生 macOS 工作台，整合本地与 SSH 会话、后续任务队列和代码审查。

Python Hot Patch Skill ↗

支持对运行中的 CPython 进程进行热补丁的 Agent Skill，保留内存状态，并提供安全点执行与独立验证。

Wait Skill ↗

面向 Coding Agent 的事件驱动等待与任务协调工具，支持被动监控、定时循环及按任务依赖组织的工作流。

JSONLine Viewer ↗

用于查看 JSONL 与 NDJSON 数据的 VS Code 扩展，支持格式化预览与大文件索引导航。
